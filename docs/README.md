# Documentation (`docs`)

## Overview
This directory contains academic manuscripts, architectural block diagrams, hardware schematics, and evaluation procedures for the SALBAR project.

## Contents
- **`Chap1.pdf`**: Chapter 1 — Introduction, Problem Background, Objectives, Scope & Limitations, Theoretical Background, and Review of Related Literature.
- **`Chap2.pdf`**: Chapter 2 — Methodology, Block Diagrams, Project Management, Materials & Resources, Gantt Chart, Program Flowcharts, and Testing Strategies.
- **`web-dashboard-ui-plan.md`**: UI Specification, 3-view screen architecture, and Light/Dark color palette for the Operator Web Dashboard.
- **`2026-10-28-gateway-setup.md`**: Technical log and pipeline specification for the LILYGO T3S3 SX1262 Gateway, Python Serial Bridge, and Web Dashboard real-time integration.
- **`schematics/`**: Hardware wiring, pinout maps, and PCB designs for the TTGO T-Beam field terminals and LoRa32 gateway.
- **`diagrams/`**: Flowcharts and sequence diagrams for BLE sync, store-and-forward mesh routing, and HITL dispatch authorization.
