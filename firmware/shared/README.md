# Shared Firmware Libraries & Protocol Definitions (`firmware/shared`)

## Overview
Shared C/C++ headers and utility classes used by both `field-terminal` and `gateway` firmware projects.

## Contents
- **Binary Packet Structs**: Bit-packed message structures minimizing time-on-air (TOA) for LoRa transmissions.
- **Message Types**:
  - `MSG_REPORT_FIELD`: Structured triage reports generated by terminal operators.
  - `MSG_REPORT_RELAY`: Compressed resident reports ingested via BLE and forwarded across the mesh.
  - `MSG_TELEMETRY`: Periodic GPS coordinates, battery voltage, and node health.
  - `MSG_DISPATCH`: Human-approved incident response commands transmitted from the base station.
  - `MSG_ACK`: Hop-by-hop delivery confirmations for store-and-forward routing.
- **Checksum Utilities**: CRC16 / CRC32 calculation routines for packet integrity verification.
