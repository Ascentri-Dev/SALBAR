# Shared Configuration & Tooling (`packages/config`)

## Overview
Shared development configurations, linting rules, code formatting guidelines, and environment variable validation templates for the SALBAR monorepo.

## Planned Contents
- **Linting & Code Style**: ESLint, Prettier, and Flake8 / Ruff configurations.
- **TypeScript Configs**: Base `tsconfig.json` configurations shared across frontends and services.
- **Environment Templates**: `.env.example` templates documenting necessary runtime keys and ports.
