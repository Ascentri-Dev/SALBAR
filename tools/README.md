# Simulation, Testing & Benchmarking Tools (`tools`)

## Overview
Scripts, simulation harnesses, and data generation utilities supporting development and thesis experimental evaluation.

## Planned Tools
- **LoRa Mesh Simulator**: Python-based simulator evaluating multi-hop store-and-forward routing behavior, hop counts, and packet collisions under varying node densities.
- **GPS Jitter & Multipath Generator**: Synthetic coordinate noise generator to benchmark the Kalman filter pipeline against Simple Moving Average (SMA) and raw GPS fixes.
- **OR-Tools vs. FCFS Benchmarker**: Automation suite running simulated disaster scenarios to evaluate response times, fatigue penalties, and detour handling between Google OR-Tools and standard first-come, first-served baselines.
- **Multilingual Dataset Generator**: Utilities for compiling and augmenting code-switched (English/Tagalog/Cebuano) disaster triage text datasets.
